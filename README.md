# Лабораторная работа 1

В компьютерной игре герой (класс Hero) может перемещаться между двумя точками (метод move) различными способами: идти пешком, ехать на лошади, лететь и т. п. Реализовать классы, позволяющие пользователю выбирать и менять в ходе выполнения программы способ перемещения героя, используя паттерн “стратегия” ([strategy](https://ru.wikipedia.org/wiki/Стратегия_(шаблон_проектирования))).
